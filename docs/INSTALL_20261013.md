# 20261013 完整预览包安装

适用 UE5.5.4、Max2026、现有 V-Ray7.40；其他版本需重新编译。完整 ZIP 已本地交付，名称 UE5MaxVraySync_FullPreview_20261013.zip。本仓库是最新测试记录，没有完整 ZIP 下载文件。

1. 保存场景并关闭 UE 和 Max，备份旧插件。
2. 将 ZIP 的 UE/UE5MaxVraySync 整个复制到工程 Plugins/UE5MaxVraySync。旧插件备份放到工程 Plugins 之外。
3. 在 Max 侦听器用 getDir #userScripts 获取脚本目录。关闭 Max，在解压目录 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\install_max.ps1 -MaxRoot '包含3dsmax.exe的Max2026目录' -UserScriptsRoot 'getDir返回的目录' -InstallNativeImporter
```

4. 重启 Max，拖入本包 Max/Start_Preview.ms。保留用户修正的启动脚本。默认接收端为 127.0.0.1:9976，同机使用一个接收器。
5. UE 启用插件、连接 Max，重新发送真实对象。旧 .max 中嵌入式 OSL 不会自动升级。

普通 GLB 保留汉化 V-Ray/Corona 选择；复杂 UE 材质的 Corona 适配未完成。ORM、程序 UV 和多 UV 保留，复杂效果仍 PARTIAL。跨机传输本机缓存引用模式 GLB 还需贴图。

过滤实验是本次 ZIP 打包后的测试，未接入默认材质、不在该 ZIP 中。恢复备份可回退。此版本不是完整生产验收版。
